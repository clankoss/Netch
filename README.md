# Netch

A personal build of [Netch](https://github.com/netchx/netch), based on version 1.9.0 and updated to .NET 10 for my own use.

The Windows x64 build is available on the [Releases page](https://github.com/clankoss/Netch/releases) and requires the .NET 10 Desktop Runtime (x64).
